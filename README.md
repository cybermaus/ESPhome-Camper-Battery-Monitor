# ESPhome-Camper-Battery-Monitor
Warns by both PushOver (without HA) and HA if I battery level gets too low.

Placeholder as need URL to put on the PCB

Features:

Deep sleep < 0.5mA average power (most goes to the step down power supply)
On a Car / Truck / Camper battery, this add barely to the cars own standby power

Needs WiFi. For when the car sits in the garage. After all when traveling I do not
need to worry about trickle charging it.
As backup, it also beeps once per hour if needed. 4 beeps with 1 minute space, then an hour.

Works with or without HA, if HA reports numbers in an hourly fashion for history
Without HA, it still reports directly to PushOver
